# Legacy Dashboard Files

These are the original HTML/jQuery-based dashboard files that have been replaced by the React frontend.

## Archived Files

- **dashboard.html** - Main legacy dashboard template
- **validation_dashboard.html** - Legacy import validation interface
- **dashboard.css** - Legacy dashboard styling
- **dashboard.js** - Legacy dashboard JavaScript (jQuery-based)
- **dashboard.js.backup** - Backup of legacy JavaScript

## Replacement

The legacy dashboard has been replaced by:
- **React Frontend**: `frontend/` folder - Modern component-based UI
- **Port**: 3000 (instead of 5001 for the old HTML dashboard)
- **Technology**: React + Material-UI (instead of jQuery)

## Why Archived

The React dashboard provides:
- Better user experience with modern components
- Real-time updates and state management  
- Professional Material-UI styling
- Better maintainability and extensibility
- Separation of frontend and backend concerns

## If Needed

These files can be restored if needed, but the React dashboard is the recommended interface for all users.

*Archived: September 2025 - Dashboard modernization*
